  <name>Task 1: Write the narration script template</name>
  <files>templates/NARRATION_SCRIPT_TEMPLATE.md</files>
  <action>
Create `templates/NARRATION_SCRIPT_TEMPLATE.md` as the format contract every Wave-2 plan copies. It must specify, in prose and one filled worked example (not a fenced code block — use an indented or quoted markdown table so it renders as a literal template a human can copy):

A header block per script: module number and slug, title, syllabus minutes (from the mapping in this plan's interfaces section), source notebook path (or "no dedicated notebook" for module 06), and a placeholder line for the Phase 7 slide-deck path to be filled in by each Wave-2 plan once it locates the actual deck file (search `.planning/phases/07-slide-decks/*-SUMMARY.md` for the path; if Phase 7 has not produced a deck yet, write "Phase 7 deck not yet available — script drafted from notebook/assessments directly" and flag it rather than inventing a path).

Per-lecture structure: a `### Lecture {module}.{n} — {title}` heading carrying an Objective line, then the two-column table with exactly these columns: `Duration | Cumulative | VISUAL | AUDIO | Cue`. Duration is `mm:ss` per row; Cumulative is the running total since the start of the whole module script. VISUAL cells use one of two anchor syntaxes: `[CELL] {notebook_stem}.ipynb § "{exact heading text as it appears in the notebook's markdown headings}"` for notebook-anchored rows, or `[SLIDE] {deck_stem}.qmd #{n}` for slide-anchored rows. AUDIO carries verbatim narration prose (what the narrator reads aloud, not a paraphrase instruction). Cue is exactly one of `[RUN CELL]`, `[ZOOM]`, `[PAUSE]`, `[CUT]`, `[NONE]`. Each lecture closes with a Recap line and an End-state line (what must be on screen at the last frame of the lecture) and a target-length note: lectures are 2-7 minutes, codealong-tagged lectures (heading suffixed literally with the text "(codealong)") may run up to 12 minutes.

Module footer: a totals line summing every lecture's duration to the module's syllabus minutes, a Pronunciation Notes section (a bullet list format: term — phonetic guide, seeded with AlphaEarth, TESSERA, GeoTessera, Guadalquivir, EPSG codes, precision@k — each Wave-2 plan adds module-specific terms), a Key Messages Used section listing which of the five canonical verbatim messages this module's script quotes (module 03 must carry "AlphaEarth vectors are unit-norm, so dot product equals cosine" and the leave-region-out cost numbers; module 04 the "1 − cosine measures representation movement" message; etc. — assign per module in Wave-2 plans, not here), and an Exercise/Quiz Callback line naming the exact `assessments/*.md` file(s) this module's script references (per SCRIPT-05).

State explicitly at the top of the template: anchors are re-verified by `tools/verify_narration_scripts.py` against the live notebook source, so a script referencing a heading that does not exist, or has been reworded, fails the check — this is intentional and catches the "anchors break silently" failure mode.
  </action>

    <automated>test -f templates/NARRATION_SCRIPT_TEMPLATE.md && grep -c 'VISUAL' templates/NARRATION_SCRIPT_TEMPLATE.md | grep -qv '^0$'</automated>
  </verify>
  <done>Template file exists, documents header block, per-lecture two-column table with the five specified columns, both VISUAL anchor syntaxes, cue tokens, module footer sections (totals, pronunciation, key messages, exercise/quiz callback), and one worked example lecture.</done>
