<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Local headless kernel process to loopback TCP | jupyter execute's underlying kernel binds a loopback TCP port without encryption; benign for single-machine local execution, worth documenting so it is not mistaken for a real finding |
| Makefile recipe to shell interpreter | The execute-notebooks recipe's correctness depends on running under bash with nullglob and array support, not Make's default /bin/sh |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-------------------|
| T-01-06 | Denial of Service | execute-notebooks recipe with a hung or slow-executing notebook | mitigate | jupyter execute is invoked with an explicit --timeout=900 per notebook, bounding worst-case wall time per file rather than allowing an unbounded hang |
| T-01-07 | Information Disclosure | nbclient's benign "Kernel is running over TCP without encryption" warning | accept | Local, single-machine headless execution has no network exposure; documented with a one-line Makefile comment per RESEARCH.md's Security Domain note so it is not mistaken for a real finding |
| T-01-08 | Tampering | requirements-colab.txt silently drifting from uv.lock if hand-edited | mitigate | The file is declared as a Makefile target with pyproject.toml and uv.lock as prerequisites and is only ever produced by uv export with the documented flags, never edited by hand |

</threat_model>
