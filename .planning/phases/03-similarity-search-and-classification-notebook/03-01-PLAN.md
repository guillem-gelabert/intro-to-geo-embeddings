  <behavior>
    - `cosine_similarity_map(query: np.ndarray, matrix: np.ndarray) -> np.ndarray`: `query` is shape `(d,)`, `matrix` is shape `(n, d)`. Computes true cosine similarity per row via `np.einsum("d,nd->n", query, matrix)` divided by `(np.linalg.norm(query) * np.linalg.norm(matrix, axis=1) + 1e-9)` — do NOT assume inputs are already unit-norm inside this function (it must stay correct if ever called with un-normalized vectors from a future provider); the notebook's own Takeaway is what demonstrates dot-product-equals-cosine specifically BECAUSE its inputs happen to be unit-norm, not because the function assumes it. Returns `np.float32` shape `(n,)`.
    - Raises `ValueError` if `query.shape[-1] != matrix.shape[-1]` with a message naming both shapes.
    - Test 1: self-similarity of a unit vector against a matrix containing itself is `pytest.approx(1.0, abs=1e-6)`.
    - Test 2: two orthogonal unit vectors (e.g. `[1,0,...]` vs `[0,1,...]` in 64-D) score `pytest.approx(0.0, abs=1e-6)`.
    - Test 3: output shape is `(matrix.shape[0],)` for `n=7`, `d=64`.
    - Test 4: cross-checked against a naive per-row Python loop (`v @ q / (norm(v) * norm(q))`) on 10 random 64-D vectors (not pre-normalized), agreeing within `1e-5`.
    - Test 5: mismatched last-dimension shapes (`query` 64-D vs `matrix` columns 32-D) raises `ValueError`.
  </behavior>
