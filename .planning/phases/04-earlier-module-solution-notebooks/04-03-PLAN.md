From `course/live/aef_cog.py` (reuse directly, do not re-implement any tile lookup or windowing logic):
```
def find_tile(lon: float, lat: float, year: int) -> dict
def read_window(url: str, bbox_4326: tuple[float, float, float, float], dst_crs: str) -> tuple[np.ndarray, rasterio.Affine]
```
`read_window` returns `(raw, window_transform)`: `raw` is `(64, H, W)` int8, nodata `-128`, already reprojected north-up via `WarpedVRT`; `window_transform` is the rasterio `Affine` for exactly that window. Do NOT dequantize before writing — the clip must ship raw int8 so the notebook demonstrates the dequantization formula itself; dequantize only inside the notebook via `course.embeddings.dequantize_aef`.

From `course/config.py`:
```
AREAS = {"bern": {"bbox_4326": (7.30, 46.85, 7.60, 47.05), "epsg": 32632}, ...}
ANCHOR_YEARS = [2018, 2021, 2024]
```
Use a small sub-bbox inside Bern's full AOI (not the whole AOI — the full-AOI window read is documented to cost 190-340 seconds and produce a large array): `(7.44, 46.94, 7.46, 46.96)`, year 2024, `dst_crs="EPSG:32632"`.
