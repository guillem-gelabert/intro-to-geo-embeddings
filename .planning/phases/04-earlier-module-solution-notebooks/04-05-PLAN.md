Earth Engine auth gotchas (from PITFALLS.md Pitfall 9, apply directly to this cell's design):
- `ee.Initialize()` without `project=` fails since earthengine-api 0.1.383 — always show `ee.Initialize(project=EE_PROJECT)`.
- Read `EE_PROJECT` from an environment variable or `getpass`, never hardcode.
- Wrap in `try/except ee.EEException`, print the registration URL (`https://console.cloud.google.com/earth-engine`) and a note about current eligibility/quota (Community 150 EECU-h/month, Contributor 1,000, Partner 100,000).
- `sampleRegions`/`getInfo()` on large regions can hit "User memory limit exceeded" / "Collection query aborted after accumulating over 5000 elements" — the illustrative code must sample a small AOI only.

From `course/config.py`: `AREAS["bern"]["bbox_4326"] = (7.30, 46.85, 7.60, 47.05)`; use this exact bbox for the illustrative `ee.Geometry.Rectangle(...)`. Catalog fact to state verbatim: dataset id `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`, availability `2017-01-01` to `2025-01-01`, image property `DATASET_VERSION` (1.1), CC BY 4.0, attribution "The AlphaEarth Foundations Satellite Embedding dataset is produced by Google and Google DeepMind."
