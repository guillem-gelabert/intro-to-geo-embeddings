<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `pipeline/build.py` (author-only) ↔ `data/` (committed, redistributed) | Everything written to `data/` by this pipeline becomes part of a redistributed course artifact; correctness and licensing compliance here have downstream legal/reputational consequences |
| `pipeline/write.py` ↔ `data/manifest.json` | The manifest is the integrity root every student download is checked against (Plan 02-05's loader); it must be computed from the actual written bytes, never hand-typed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-18 | Tampering | `manifest.json` sha256 values | mitigate | Computed directly from `path.read_bytes()` after `write_table` completes, never hand-entered or copied from a prior run |
| T-02-19 | Information Disclosure | Redistributing derived data without correct attribution (DATA-06) | mitigate | `render_data_card`'s exact-substring tests (Task 2) make a missing/altered attribution string a failing test, not a silent legal gap |
| T-02-20 | Repudiation | AlphaEarth `dataset_version` cannot be read from the GCS source (02-RESEARCH.md Pitfall 6, "no version metadata") | accept | Hand-recorded as `"1.1"` in the provenance dict per the EE catalog page value known at research time; documented in the provenance dict itself so a future reader knows this field is manually maintained, not source-verified |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages introduced this task (uses only already-vetted `pyarrow`, `geopandas`, `hashlib`, `argparse`, `subprocess`) |
</threat_model>
