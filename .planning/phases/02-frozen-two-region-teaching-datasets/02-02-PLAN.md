## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | Remote COG bytes over `/vsicurl/https://` | mitigate | HTTPS-only URL (never plain HTTP); GDAL/rasterio's own TLS verification; the array shape/dtype assertions in the network test catch a structurally wrong response (e.g. an HTML error page returned instead of a TIFF) before it reaches downstream code |
| T-02-04 | Denial of Service (self-inflicted) | Point sampling strategy | mitigate | `sample_points_from_window` indexes an already-fetched in-memory array; the module never loops a `.sample()`/`.read()` call per point against the remote COG (Pitfall 4) |
| T-02-05 | Repudiation | Tile provenance | mitigate | `find_tile`'s returned `url` and `utm_zone` are recorded verbatim by `pipeline/extract_aef.py` (Plan 02-07) into the table's provenance, so every embedding traces back to the exact source tile |
