  <read_first>course/schema.py; .planning/phases/02-frozen-two-region-teaching-datasets/02-RESEARCH.md (section "Extraction Mechanics, Verified End to End" → step 3 "Dequantization + renormalization"); .planning/research/PITFALLS.md (Pitfall 1, canonical `dequantize_aef` helper)</read_first>
  <files>course/embeddings.py, tests/test_embeddings.py</files>
  <behavior>
    - `dequantize_aef(raw: np.ndarray) -> np.ndarray` takes an int8 array with the band axis first (shape `(64, ...)` — either `(64,)` for one vector, `(64, H, W)` for a window, or `(64, N)` for N sampled points).
    - A -128 value in ANY band at a given spatial/point position marks that whole position as nodata: the output at that position is NaN across all 64 bands.
    - Valid positions: `d = (v / 127.5) ** 2 * np.sign(v)` element-wise on the int8-as-float32 array, then L2-renormalize along axis 0 (`d / (norm(d, axis=0) + 1e-9)`).
    - Output dtype is always float32.
    - Test 1: a `(64,)` all-valid vector renormalizes to norm 1.0 within `atol=1e-6`.
    - Test 2: a `(64, 3, 3)` window where one pixel has `raw[:, 1, 1] = -128` (all bands) produces NaN at `result[:, 1, 1]` and finite unit vectors everywhere else.
    - Test 3: negative int8 inputs preserve sign after the square operation (regression test for `np.sign(v)` — the formula must not silently produce an all-positive result).
    - Test 4: a `(64, 5)` batch of 5 points dequantizes independently (no cross-point leakage) — 5 different synthetic vectors in, 5 correctly-normalized vectors out matched by index.
  </behavior>
  <action>
    Create `course/embeddings.py` with `NODATA = -128` and `dequantize_aef` implementing the behavior above using `np.any(raw == NODATA, axis=0, keepdims=True)` for the mask and `np.where(mask_broadcast, np.nan, unit)` for the output. This is the ONE shared helper — no other module in this phase re-implements the dequantization formula; every consumer (`course/live/aef_cog.py` in Plan 02-02, `pipeline/extract_aef.py` in Plan 02-07) imports `dequantize_aef` from here per PITFALLS.md's Pitfall 1 guidance.
  </action>
