<objective>
Build the sampling design: read WorldCover once per region, stratify sample locations by class with caps that prevent any single class from dominating, assign stable IDs and a spatial block grid, and persist the design so it is drawn exactly once and reused for all three anchor years.

Purpose: this is the "frozen dataset too clean or too small" pitfall's direct countermeasure (PITFALLS.md Pitfall "frozen dataset too clean") and what makes 2018/2021/2024 tables joinable on `sample_id` (DATA-03). The block grid this plan computes is the reference answer the dataset-aliveness guard (Plan 02-12) and any future notebook's own block computation can check against.
Output: `pipeline/areas.yaml`, `pipeline/sample_design.py::generate_sample_points`, unit-tested with a synthetic WorldCover array (no network).
</objective>
